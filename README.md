# Yalidine JavaScript SDK

Monorepo containing the official JavaScript SDK and framework integrations for the Yalidine API.

This project provides tools to integrate Yalidine shipping and delivery services into modern JavaScript applications, with a framework-agnostic core SDK and optional framework integrations.

## Packages

- `yalidine-sdk` — Core SDK with API helpers and business logic
- `yalidine-astro` — Astro integration for configuring and using the SDK

## Getting started

- If you are using Astro, start with the Astro integration.
- Otherwise, use the core SDK directly in a Node.js environment.
