# Security Policy

## Supported Versions

Only the latest published versions of the following packages are supported:

- yalidine-sdk
- yalidine-astro

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, report it by email to:

yalidine.sdk@outlook.com

If email is not available, you may use GitHub's private vulnerability reporting feature.

We aim to acknowledge reports within 72 hours.
